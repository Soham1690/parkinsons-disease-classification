Clinical framing

Built to feel clear, modern, and medically relevant

Instead of looking like a notebook dump, this interface presents the project as a polished screening demo with guided terminology, cleaner user flow, and easier interpretation.

Relevant terminology

Uses medically meaningful language such as voice biomarkers, Parkinsonian signal, screening output, and model confidence.

Easy user flow

Users can start with a stored voice record, then move to manual biomarker input without feeling lost in raw technical details.

Better interpretation

Results are shown with structured explanation, probability bars, risk wording, and key record details.

Important notice

This project demonstrates a machine learning workflow. It is useful as a product showcase and educational interface, not as a replacement for neurological assessment.
